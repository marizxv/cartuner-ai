# CarTuner AI — Automotive Performance Dataset

A structured dataset and data preparation pipeline for predicting
post-modification vehicle performance. Built as a Data Preparation
for AI coursework project.

## What This Is

A documented dataset mapping car modification combinations
(ECU remaps, turbo upgrades, exhaust systems etc.) to real-world
performance outcomes (horsepower, 0–100 km/h time, top speed).
Intended as a training dataset for a future recommendation model.
